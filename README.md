# 🎨 AstrBot Rainnya Image Plugin（魔改增强版）

> 本项目 `astrbot_plugin_rainnya_image` 基于上游原版 [`astrbot_plugin_nova_newimage`](https://github.com/YumenoSayuri/astrbot_plugin_nova_newimage)（原作者：辉宝，v1.4.1）的 **AGPL-3.0 fork 魔改增强版**。
> 保留了原版全部能力，并大幅增强：多提供商架构、WebUI 全量管理、异步生图、LLM 自主调用、生图日志等。

## 🌟 项目特色

相比原版，魔改版最直观的变化：**配置全部搬到 WebUI，生图全程自动化**，不再需要手写 JSON 或依赖 AstrBot 的 provider 配置。

- **多提供商架构（WebUI 添加）**：像 AI coding 平台一样，在 WebUI 里添加 N 个提供商（Gemini / OpenAI / NovalAI 模板），各自填 API Key + BaseURL，每个提供商下挂自己的模型列表，互不干扰
- **WebUI 全量管理面板**：提供商管理 / 次数管理 / 生图日志 / 全量设置 四个 Tab；「全量设置」把 AstrBot 配置面板的所有配置项整体搬到 WebUI，所见即所得
- **NovelAI 路由**：文生图 / 图生图、v4_prompt 提示词、ZIP 响应自动解压
- **LLM 工具全家福（7 个）**：生图（图 + 文）、查模型、查次数、查时间线、调历史图、使用统计、查预设，主对话 LLM 可自主调度
- **异步生图 + 统一时间线**：工具调用不阻塞对话，后台生成完成自动发图；所有图片落盘并汇总到时间线，随时可查可删
- **按群切换模型 + 模型配额**：每个群独立切换模型；模型可按次消耗不同配额，支持默认参数与分辨率限制
- **废弃 AstrBot provider_id**：不再使用 AstrBot 的 provider_id 下拉，连接方式完全由 WebUI 里的提供商接管

## 🚀 魔改增强特性（相对原版）

### ⚡ 异步生图
- **LLM 工具调用不再阻塞对话**：`generate_image` 立即返回「开始生成」，实际生图在后台任务执行，完成后自动发送图片到会话
- 后台任务受群并发槽位限制，防止任务堆积

### 🖥️ WebUI 管理面板（插件 Pages）
- 内嵌于 AstrBot WebUI 的完整管理页，替代/补充难懂的配置面板
- 板块：**提供商管理**（WebUI 添加多提供商，每个提供商下管理自己的模型列表/配额/参数/分辨率限制）、**次数管理**（用户/群组查询与充值）、**生图日志**（时间线可视化、筛选、删除）、**全量设置**（AstrBot 配置面板全量搬运，友好表单）
- 纯 HTML/CSS/JS 实现，跟随 AstrBot 亮/暗主题

### 🎛️ 多模型 + 配额 + 详细参数
- **模型列表多行配置**：`模型名;每次消耗配额;给LLM的说明;参数JSON`
- **按模型消耗不同配额**：不同模型一次生图扣不同次数；配额不足明确报错（`需 X 次，剩余 Y 次`）
- **按模型详细参数**：每个模型可配置默认生成参数（size/temperature/max_tokens/steps/negative_prompt 等）
- **指令显式带参**：`>>文生图 描述 size:4K temperature:0.9 ...` 多个参数空格分隔，覆盖模型默认；参数类型/范围严格校验并报错
- **LLM 自主带参**：LLM 通过工具 `params` 参数携带，超范围自动夹取
- **模型分辨率限制**：可限制某模型仅支持 `1K`（如 `{"sizes":["1K"]}`），指令指定不支持分辨率报错、LLM 自动夹取

### 🤖 LLM 自主工具调用
- 注册 3 个 LLM 工具：`generate_image`（生图）、`query_generation_quota`（次数查询）、`query_generation_history`（时间线查询）
- 主对话 LLM 可自主判断调生图工具；次数用完/画完剩余次数均回传 LLM 知晓

### 📜 生图日志
- 全部生图落盘保存（`data/generations/<群>/<时间戳>.png`）+ 统一时间线记录（保留最近 500 条）
- `>>生图日志` 指令：查询（默认本群/全局/分页）/ 单条查询（含图片）/ 删除（单条/时间段/群）

### 📝 帮助菜单可配置
- 配置面板新增 `help_menu`，`>>生图帮助` 显示自定义内容；留空用内置默认（`>>` 前缀）

### 🔧 其他增强
- 管理员增加次数不受持有上限限制
- API 5xx 错误友好化（不再回显 nginx HTML）
- 管理员/群次数查询显示豁免（∞）

## ✨ 原版功能特性（保留）

### 🖼️ 图生图功能
- **40+ 预设风格**：手办化、Q版化、Cos化、痛车化、痛屋化、真人化等多种风格转换
- **多种输入方式**：直接发送图片 + 指令 / 回复带图片的消息 + 指令 / @用户 + 指令（使用其头像）
- **自定义 Prompt**：使用 `bnn <提示词>` 进行完全自定义创作
- **批量处理**：自定义模式支持最多 5 张图片同时处理

### ✏️ 文生图功能
- 使用 `/文生图 <描述>` 直接从文字生成图像

### 🔀 API 双路由
- **Gemini 原生 API**：开启 `is_gemini_api` 开关后，使用 Gemini `generateContent` 格式发送请求，支持所有 Gemini 原生参数（包括自定义域名反代）
- **OpenAI 兼容 API**：默认模式，使用 `/v1/chat/completions` 格式，兼容 OpenRouter 等各种中转站
- **一键切换**：通过配置面板的开关按钮即可切换，无需修改任何代码

### 🛡️ Gemini 增强功能（Gemini 模式专属）
- **安全过滤等级**：可配置 `BLOCK_NONE`（不过滤）、`BLOCK_ONLY_HIGH` 等多种等级，突破默认安全限制
- **高分辨率生成**：支持 1K/2K/4K 分辨率参数，可设置全局默认值
- **高分辨率白名单**：只有白名单中的用户才能在指令中输入 `2K`/`4K` 自动提取为分辨率参数

### 🎁 次数管理系统
- **用户次数限制**：按 QQ 号独立计算使用次数
- **群组次数限制**：按群号计算群内共享次数
- **每日签到**：发送「辉宝赐福」获取免费次数
- **随机/固定奖励**：可配置签到奖励模式

### 🔐 权限管理
- **黑白名单**：支持用户/群组级别的黑白名单
- **管理员豁免**：管理员不受次数限制
- **并发控制**：可限制单个群聊同时处理的任务数

### 🔧 管理功能
- **API Key 轮换**：支持多 Key 自动轮换使用
- **动态预设管理**：通过指令添加/修改预设
- **代理支持**：内置网络代理配置

## ⚙️ 配置说明

在 AstrBot 管理面板的「插件管理」中找到本插件进行配置。**推荐配合插件自带 WebUI 管理面板使用**（插件详情页 → Pages）。

### 模型配置（重点）
`model` 项支持**多行填写**，每行一个模型，格式：

```
模型名;每次消耗配额;给LLM的该模型说明;参数JSON
```

示例：
```
gpt-image-2;1;标准生图，速度快;
gpt-image-2-large;3;高分辨率精修;{"sizes":["4K"],"temperature":0.8}
gemini-flash;1;性价比之选;{"sizes":["1K"]}
```

- 参数 JSON 可选：`size`/`temperature`/`max_tokens`/`steps`/`negative_prompt`，`sizes` 键限制该模型可用分辨率（如 `{"sizes":["1K"]}`）
- 兼容旧格式：仅模型名 / `模型名;配额` / `模型名;配额;说明`
- 群内用 `>>切换模型 <序号>` 切换（仅管理员）

### 其他配置

> API 连接相关（`provider_id`/`api_url`/`api_keys`/`is_gemini_api`）已废弃，**统一改由 WebUI「提供商管理」接管**：添加多个提供商（Gemini/OpenAI/NovalAI 模板）、各自填 API Key + BaseURL、下挂模型列表。其余配置项在 WebUI「全量设置」中即可完成，以下列出供参考：

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `prefix` / `extra_prefix` | 开关 / 字符串 | 是否要求指令带前缀 / 自定义前缀（如 `bnn`） |
| `use_proxy` / `proxy_url` | 开关 / 字符串 | 是否使用代理 / 代理地址 |
| `download_timeout` / `download_retries` | 整数 | 图片下载超时（秒）/ 下载重试次数 |
| `api_timeout` | 整数 | API 请求超时（秒） |
| `safety_level` | 字符串 | Gemini 安全过滤等级 |
| `image_size` | 字符串 | Gemini 全局默认分辨率 |
| `hires_whitelist` | 列表 | 高分辨率白名单 |
| `user_whitelist` / `user_blacklist` | 列表 | 用户白名单 / 黑名单 |
| `group_whitelist` / `group_blacklist` | 列表 | 群白名单 / 黑名单 |
| `enable_user_limit` / `enable_group_limit` | 开关 | 用户/群组次数限制 |
| `user_count_cap` | 整数 | 用户持有次数上限（0=不限，签到受此限制，管理员手动增加不受限） |
| `group_task_limit` | 整数 | 单群同时处理任务数 |
| `enable_checkin` | 开关 | 每日签到 |
| `checkin_fixed_reward` | 整数 | 签到固定奖励次数 |
| `enable_random_checkin` | 开关 | 随机奖励模式 |
| `checkin_random_reward_min` / `max` | 整数 | 随机奖励下限 / 上限 |
| `help_menu` | 文本 | `>>生图帮助` 显示的自定义内容（留空用默认） |
| `prompt_list` | 列表 | 预设 prompt（`触发词:提示词`，每行一个） |

## 🔧 常见问题

### Q: 模型配置怎么填？
A: `model` 项每行一个模型：`模型名;每次消耗配额;给LLM的说明;参数JSON`。如 `gpt-image-2;1;标准;`。可用 `>>切换模型` 在群内切换。

### Q: 某些模型只支持 1K 怎么限制？
A: 该模型参数 JSON 里写 `{"sizes":["1K"]}` 即可，指令指定更高分辨率会报错，LLM 调用会自动夹取。

### Q: LLM（雨喵）能自主画图吗？
A: 能。主对话 LLM 支持 function calling 时会自动带上 `generate_image` 工具，用户说「帮我画一张…」即可触发，扩写提示词后调用。

### Q: WebUI 管理面板在哪？
A: AstrBot 管理面板 → 插件详情页 → Pages 打开。包含提供商管理、次数管理、生图日志、全量设置四个 Tab。API 连接（Key/BaseURL）与模型列表都在「提供商管理」里配。

### Q: 生成失败显示「服务端繁忙或超时」？
A: 这是 API 服务端 5xx（如 504）的友好提示，可加大 `api_timeout` 或稍后重试/换模型。
